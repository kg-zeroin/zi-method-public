# ZI-Method: 제로인 펀드평가 방법론 AI 학습 데이터

## 📖 프로젝트 개요

**ZI-Method**는 ㈜KG 제로인의 펀드평가 방법론을 AI 학습에 활용할 수 있도록 구조화된 마크다운 형태로 변환한 데이터 프로젝트입니다.

금융 AI 모델 학습을 위한 고품질 한국어 펀드평가 방법론 데이터를 제공합니다.

## 🎯 프로젝트 목적

- **AI 학습 데이터 확보**: 펀드평가 방법론을 구조화된 텍스트 데이터로 변환
- **데이터 접근성 향상**: PDF 형태의 문서를 검색 가능한 마크다운으로 변환
- **수식 보존**: LaTeX 형태로 수학적 공식 완벽 변환
